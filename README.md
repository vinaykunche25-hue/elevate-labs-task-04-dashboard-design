# Task 4 – Dashboard Design

## Objective
Design an interactive dashboard for business stakeholders.

## Deliverables
- `dashboard/interactive_sales_dashboard.html` – interactive dashboard
- `dashboard_summary.pptx` – PPT stakeholder summary
- `data/sales_financial_dataset.csv` – sales/financial dataset
- `screenshots/dashboard_preview.png` – dashboard preview
- `README.md`

## Features
- KPI cards: Sales, Profit, Orders, Profit Margin
- Filters: Year, Region, Category, Channel
- Monthly time-series analysis
- Sales by Category, Region and Channel
- Stakeholder-focused business insights

## How to use
Open `dashboard/interactive_sales_dashboard.html` in a browser and change the filters. KPI cards and charts update automatically.

## Power BI / Tableau
The CSV is structured so it can also be imported into Power BI or Tableau for a native dashboard.
